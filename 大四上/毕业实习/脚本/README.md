## 使用方法
先构建好环境，环境配置都在requirement.txt，可以通过anaconda构建哦

接着用把自己要做的文件夹参照压缩包里的文件结构放入项目根路径

然后把别人的文件夹名字替换成你自己的文件名（多人参与构建，谁都有可能，反正只需要改一次就可以一直使用）
一共有 3 个 分别在：image_checker.py第22行 generate_correct.py第129行 test.py第73行

之后先运行test.py生成模板图像

再运行generate_correct.py下载词典里的正确图像 记住不要科学上网 大概要花2分钟左右

最后运行image_checker.py一个个比对 我们这边提供了原文对照 自动换行 当然换列的时候就需要您动动手指了~

最后的结果文件会存在你名字的文件夹下的processed_page_xxx中
